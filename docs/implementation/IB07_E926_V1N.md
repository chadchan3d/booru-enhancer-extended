## Native sources

Observed source row contract:

- `#post-information li.source-links`;
- one or more `.source-link a[href]` children.

This observed post exposed three source links.

The current Post model stores one scalar `source`, not an array. IB07 does not change the model shape. Production therefore stores the first native source anchor and leaves the remaining source URLs represented only by the native page.
