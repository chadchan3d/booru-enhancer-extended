# Research notes

These notes preserve the evidence-driven design work behind the next architecture pass for **Booru Enhancer Extended**.

The method is **user problem first**: identify a demonstrated browsing problem, compare the sources that solve that problem, synthesize the strongest behavior, then decide whether it belongs in Core, Core + Adapter Contract, Site-Specific behavior, or should be rejected.

- [`RESEARCH_SNAPSHOT.md`](RESEARCH_SNAPSHOT.md) — user problems and preliminary best-in-class synthesis.
- [`SOURCE_CORPUS.md`](SOURCE_CORPUS.md) — reviewed projects, roles, licensing posture, and the generalization rule.

These are research snapshots, not promises that every discussed feature or site will ship. Third-party source trees are not vendored here merely for convenience.
